# Матвей Воронов — портфолио графического дизайнера

Сайт: **https://design.openline.one/** (English: https://design.openline.one/en/)

Портфолио графического дизайнера: айдентика, логотипы, брендбуки, SMM-наборы, бренд-стратегия. На сайте шесть кейсов 2023–2025 годов, страница «О себе», отзывы заказчиков и бриф на проект.

## Что на сайте

- **Работы** — шесть кейсов: Resilience Initiative, SALT, Федерация адаптивного спорта, Taiwan Mountain Essence, «Сердце Кольского», «Киберправда». У каждого своя цветовая полоса, галерея и описание задачи.
- **О себе** — подход к работе и образование.
- **Отзывы** — отзывы заказчиков.
- **Бриф** — два пошаговых брифа (для коммерческих проектов и для гражданских активистов) с сохранением черновика в браузере.
- Русская и английская версии с переключателем RU / EN, светлая и тёмная темы.

## Как устроен репозиторий

Статический сайт без сборки и зависимостей: чистый HTML, CSS и JavaScript.

| Путь | Что внутри |
|---|---|
| `index.html` | русская версия: разметка, стили и рендер страниц |
| `en/index.html` | английская версия |
| `assets/data.js`, `assets/data.en.js` | тексты кейсов, «О себе», отзывы |
| `assets/briefs.js`, `assets/briefs.en.js` | вопросы брифов |
| `assets/ui.js` | общая логика интерфейса |
| `assets/*.jpg` | иллюстрации кейсов, обложки, превью для соцсетей |

Чтобы посмотреть локально, достаточно запустить любой статический сервер в корне репозитория, например `python -m http.server`.

## Публикация

Каждый push в `main` автоматически выкладывает сайт через GitHub Actions (`.github/workflows/deploy.yml`).
